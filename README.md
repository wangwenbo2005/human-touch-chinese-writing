# human-touch-chinese-writing

中文人味写作 Skill —— 撰写与改写中文文章，产出有真实信息、独立判断、自然语言、成熟段落结构、无明显"AI 味"的成稿。

## 这不是什么

**不是一个 AI 高频词黑名单。**&#8203; 把"赋能"换成"推动"、把"不仅……更……"改成两句普通陈述，AI 味通常还在。一篇文章用正确的、漂亮的、完整的话，说了一堆谁都知道、却没人需要再听一遍的内容，就算一个高频词都不出现，读起来依然是空转。

本 Skill 只做三件事：**把话说实，把判断说清，把形式放自然**。词汇表、句式表、标点表都是副产品，不是目标。真正研究过问题、有明确取舍的作者，用几个"值得注意的是"完全没有问题——这些词本身不是罪证。

## 核心原则

**判断优先级：信息 > 判断 > 结构 > 语言。**&#8203; 低层做得再好，也补不了高层的空缺。

写完用五个问题量一遍：

1. 有没有大量通用词？——逐个问"它在这里指什么具体的事"，答不出就删
2. 有没有靠对立和升华制造深度？
3. 读完获得了多少新信息？
4. 有没有明确的思想取舍？
5. 删掉结尾会不会更好？

**最终标准**：把文中所有单位名称、时间、地点替换掉，如果还能原封不动适用于别的场合，说明它没有真正说出任何一件事。

## 使用方式

写一篇评论、公众号文章、新闻稿、人物报道、调研报告、学术随笔，或对已有文稿说"帮我去掉 AI 味""写自然一点""润色成人话"，Skill 自动触发。完整工作流六步：

1. **定体裁** —— 评论 / 公文 / 学术 / 特稿，自由度完全不同
2. **备料** —— 材料不够就不要写，宁从小切口写八百字
3. **先定判断，再动笔** —— 平均分配注意力是最典型的 AI 病
4. **成文** —— 遵守段落、标点、句式、结构的硬约束
5. **机器扫一遍** —— 用下面的体检脚本
6. **三遍审校** —— 校内容、校逻辑、校形式；改不动的地方直接删

## 体检脚本

```bash
python scripts/ai_smell_check.py 文稿.md          # 标准报告
python scripts/ai_smell_check.py 文稿.md --top 20 # 每类展开更多条目
python scripts/ai_smell_check.py 文稿.md --json   # 结构化输出
cat 文稿.md | python scripts/ai_smell_check.py -  # 从标准输入读取
```

扫描五个维度，全部给出行号定位：

| 维度 | 检查内容 |
|---|---|
| 词汇 | 六类高频抽象词，重点词标 ★ |
| 句式 | 13 种模板句式（"不是A而是B""从A到B从C到D"……），每条附病灶说明 |
| 标点 | 引号（按对数）、冒号、破折号、分号、问号的每千字密度 |
| 段落 | 单句成段占比、平均段长、段长变异系数（专抓"每段都四句话"的机械均匀） |
| 结构 | 小标题 / 加粗 / 分隔线密度，防止文章写成 PPT 提纲 |

**脚本只负责"指出来"，不判断对错。**&#8203; 命中的每一处都要人工确认：这个表达在这里是否真的指向了具体的事。

### 调参

所有阈值集中在脚本顶部的 `TH` 字典。觉得误报或漏报，优先调这三项：

- `single_sent_ratio`（默认 0.35）—— 单句成段占比告警线
- `para_cv_max`（默认 0.38）—— 段长变异系数下限，低于此提示节奏机械
- `quote_per_k`（默认 6.0）—— 引号对数每千字告警线

## 判断层速查：十二种思维套路

词汇和句式是皮，思维套路才是骨。完整解析见 `references/thinking.md`：

伪辩证 · 伪深刻 · 强行升华 · 万能三分法 · 万能解决方案 · 概念替代事实 · 全知视角 · 过度解释 · 平均分配注意力 · 结论先行论证补位 · 情绪表演 · 完美闭环

自查口令：**每一处"深刻"的地方，问它在解释哪一个具体的因果关系；每一处"全面"的地方，问它回避了哪一个必须做的取舍。**&#8203;

## 公文特化

公文不是散文，把评论体的标准直接套上去会出问题。`references/official-docs.md` 单独处理：程式化与空洞的边界、判断强度分级表（"彻底解决"→"着力解决"）、小标题怎么写才有思想、五环节写作流程，以及三档水平（套话型 / 任务型 / 判断型）的同一材料对照。

核心分界一句话：**普通的八股文是把一件事情写得很重要；真正优秀的公文，是准确判断这件事情为什么重要、重要到什么程度，以及接下来究竟应该怎么办。**&#8203;

## 免责的诚实说明

词表和阈值来自对常见中文 AI 输出的经验性归纳，不是大规模语料统计的严格词频排名。这些表达人类作者同样大量使用，AI 也并非独有——真正值得警惕的是它们**成群地、重复地、脱离语境地**出现。机器能看见的只是形式层；词汇和标点全部合规的文章，仍可能从头到尾空转。
